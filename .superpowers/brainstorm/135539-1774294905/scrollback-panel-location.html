Where should the scrollback panel live?

This panel shows session history with native browser scrolling (touch-friendly on mobile)

A

Slide-out drawer (right side)

A panel that slides in from the right when you tap a "History" button. Overlays the terminal. Close to go back to the live terminal. Like a chat history drawer.

Pros

  • Terminal stays full-size when not scrolling
  • Works identically on desktop and mobile
  • Clear separation between "live" and "history" modes

Cons

  • Context switch — you leave the terminal to read history
  • Extra tap to open/close
B

Split view (top: scrollback, bottom: terminal)

The terminal area splits vertically. Top half is scrollable history (HTML), bottom half is the live xterm.js terminal. Draggable divider.

Pros

  • See history and terminal simultaneously
  • No context switch

Cons

  • Both areas get smaller
  • Cramped on mobile
  • More complex layout
C

Full-screen overlay toggle

A button toggles between the live terminal and a full-screen scrollable history view. Like switching tabs. The history view is a plain scrollable div with the raw terminal output rendered as text.

Pros

  • Maximum space for both modes
  • Simple implementation
  • Great on mobile — full-screen native scroll

Cons

  • Can't see terminal and history at same time
  • Toggle adds a step
